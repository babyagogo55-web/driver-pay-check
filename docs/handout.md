# 試作をお渡しするときの案内文

LINE やメールにそのまま貼って送れる文面です。

---

運行日報・給与チェックの試作版です。スマホで下のアドレスを開いてください。

https://babyagogo55-web.github.io/driver-pay-check/

**1. ホーム画面に置く**
- iPhone：Safari で開く → 下の「共有」ボタン →「ホーム画面に追加」
- Android：Chrome で開く → 右上の「︙」→「ホーム画面に追加」

**2. はじめの設定（5〜10分）**
基本給や単価などは、ご自身で入れていただく作りです。給与明細を手元に置いて、画面の順番どおりに進めてください。分からない所は空欄のまま進めて、あとで「設定」から入れられます。
すぐ触ってみたい場合は「まず見本の値で試してみる」を押してください（見本の金額は本物ではありません。あとで消して始め直せます）。

**3. 毎日の記録**
「🎤 話して入力」を押して「A市場 青果50、距離280キロ」のように話すと、自動で記録に入ります。マイクが使えない場合は「文字で入れる」を押してください。

**Googleマップ連携について**
使うかどうかは自由です。使わなくても、記録・給料の計算・明細との照合はすべてできます。距離や時間を自動で出したい場合だけ、ご自身で Google Cloud の登録（カード登録が必要）とキーの作成をしていただく形です。

**データについて**
記録や金額はスマホの中だけに保存され、会社にもこちらにも送られません。機種変更に備えて、月に1回「設定 → バックアップを保存」をおすすめします。

試作なので、使いにくい所や計算が合わない所があれば教えてください。

---

※ QRコードが必要なときは、パソコンの Chrome で上のアドレスを開き、アドレスバー右の共有ボタン →「QRコードを作成」で作れます。
