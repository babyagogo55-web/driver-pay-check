# 使い方（ドライバー本人向け）

このアプリは、毎日の仕事を**30秒で記録**しておくと、月の給料（だいたいの額）と手当の中身を自動で計算し、**会社から届いた明細と同じかどうか**を確かめられるものです。

- 記録はこのスマホの中だけに残ります。会社や他の人には送られません
- 電波が悪い場所でも記録できます

---

## 1. はじめに1回だけやること

### スマホのホーム画面に置く

- **iPhone**：Safari でアプリのページを開く → 画面下の「共有」（四角から矢印が出ているマーク）→「ホーム画面に追加」
- **Android**：Chrome でページを開く → 右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）

次からはホーム画面の「運行日報」のアイコンから開きます。

### 金額を本当のものに直す（「設定」タブ）

最初は**仮の金額**が入っています。わかる所から直してください。わからない所はそのままで大丈夫です。

1. **あなたの情報**：名前と営業所（会社に出すレポートに載ります）
2. **基本給**：月の基本給
3. **距離手当の単価**：1kmあたりの金額（今は5円）
4. **行き先**：市場などの名前を、正しい名前に書き換えます。足りなければ「＋ 追加」
5. **荷物の種類**：荷物の種類と数え方（点・枚など）
6. **単価表**：行き先ごと・荷物ごとの「1点いくら」
7. **締め日**：給料の締め日（月末締めなら「月末締め」のまま）

全部直したら、いちばん上の「書き換え終わった」を2回押すと、黄色い注意が消えます。

### 値上げがあったとき

「単価表」の下で、値上げした日を選んで「値上げを登録（この日から）」を押し、**上がった所だけ**新しい金額を入れます。空欄の所は前の金額のまま使われます。値上げ前の日は自動で古い金額、値上げ後は新しい金額で計算されます。

---

## 2. 話して記録する（いちばん楽）

記録画面のいちばん上の **「🎤 話して入力」** を押して、そのまま話します。話し終わると**自動で記録に入ります**。

話し方の例：

> 「いつもの便A、太田垣 青果55、第一柿 ケース20、東日本 パレット4 高速、距離290キロ」

- **いつもと違う所だけ言えば大丈夫です**。「いつもの便A、太田垣 青果55」なら、いつものルートを呼び出して太田垣の青果だけ55点にします
- あとから「第一柿 ケース25」とだけ言うと、そこだけ直ります
- 「高速」と言うと、その前に言った行き先が高速道路ありになります。「高速なし」で取り消し
- 距離は「距離290キロ」。メーターなら「出発123456、帰着123736」
- 「メモ」と言うと、その後ろはそのままメモになります（例：「メモ 渋滞で遅着」）
- 休みの日は「休み」
- 間違えたら「元に戻す」

**聞き取ってもらえない名前があるとき**：「○○がわかりませんでした。これは？」と出るので、正しい行き先（または荷物）を押します。次からはその言い方でも通じるようになります。

> マイクを押しても動かないとき：「文字で入れる」を押し、出てきた欄を押してから、キーボードのマイクのボタンで話して「反映」を押します。

## 2-1. Googleマップで距離と時間を見る

「設定 → Googleマップ連携」に**営業所の住所**を、「設定 → 行き先」の各行き先に**住所か施設名**（例：山形市中央卸売市場）を入れておくと、記録画面の「ルート・時間」に次が出ます。

- **🗺 Googleマップでルートを見る**：その日の道順（営業所→行き先→営業所）がGoogleマップで開きます。距離と時間はマップの画面で見られます
- **APIキーを入れた場合**：距離と運転時間の目安がアプリの中に自動で出ます。「この距離を入れる」で1回押せば距離が入ります。いつものルートはスマホが覚えるので、2回目からは電波がなくても出ます
- 入れた距離が地図と大きく違うと「⚠ 打ち間違いか、寄り道・回り道を確認」と出ます

> 距離手当はメーターの距離が正しい距離です。地図の距離は「だいたいの目安」と「打ち間違いの確認」に使ってください。

**出発・帰着の時刻**も入れておくと、拘束時間が出て、月の合計が「集計」に出ます。話して入れるときは「出発21時半、帰着5時」。

## 2-2. ボタンで記録する（30秒）

1. アイコンを押すと、**今日の記録**が開きます
2. **「いつものルート」のボタン**を押します（行き先・荷物・点数・距離がまとめて入ります）
3. いつもと違う所だけ直します
   - 点数：**−** と **＋** のボタン、または数字を押してテンキーで入力
   - 行き先を増やす：「＋ 行き先を追加」
   - 高速道路を使った：「高速道路を使った」を押してチェック
4. **走行距離**を入れます。メーターを見て「距離を入れる」に直接入れるか、「メーター値で」にして出発と帰着のメーターを入れると自動で計算します
5. おわり。**保存ボタンはありません**。入れたそばから自動で残ります

その他のボタン：

- **前回をコピー**：前に記録した日と同じ内容を入れます
- **休み・運行なし**：休みの日はこれを押しておくと、カレンダーで「休」になります
- **メモ**：キーボードのマイクのボタンを押すと、話して入力できます

### 「いつものルート」を作る

ある日の記録を入れたあと、画面のいちばん下の「この内容を『いつものルート』に登録」を押して、名前（例：月曜の夜便）を付けます。次からはボタン1つで呼び出せます。

### 記録を忘れた日

- 記録画面の上に「まだ記録していない日がN日あります」と出ます
- **カレンダー**タブでは、記録していない日が**赤い「未」**で出ます。押すとその日の記録が開きます
- 日付の横の ◀ ▶ で前の日・次の日へ動けます

### 忘れないように通知を出す

「設定」→「記録忘れ防止」で時刻を決めて「カレンダーに毎日の通知を追加」を押すと、スマホのカレンダーに毎日の通知が入ります。

---

## 3. 月の給料を見る（「集計」タブ）

- **総支給額（概算）**＝基本給＋距離手当＋運行内容手当
- 行き先ごと・荷物の種類ごと・日ごとの金額
- ⚠ が出ている所は、単価が入っていない・距離が入っていないなど、直したほうがよい所です。押すとその日が開きます
- 税金などを「控除」に入れると、手取りの目安も出ます（入れなくても構いません）

---

## 4. 会社の明細と比べる（「照合」タブ）

1. 給料明細と運行内容手当の明細が届いたら、「照合」タブを開きます
2. **明細の月合計**に、明細に書いてある金額を写します → 自分の記録との**差**が出ます
   - **赤いマイナス**：会社の金額のほうが少ない（もらい漏れの疑い）
   - **青いプラス**：会社の金額のほうが多い（他の人の分が入っている疑い）
3. 明細に日ごとの金額が書いてあれば、「明細に日ごとの金額が書いてある」を押して、日ごとの金額を写します
   - 差がある日は**赤い枠**で目立ちます
   - 何日分もまとめて入れたいときは「まとめて貼り付け」に `10/1 12345` のように1行1日で入れて「取り込む」
4. 差がある日は、状況（問い合わせ中・翌月加算予定・解決済みなど）とメモを残せます

### 会社に聞くとき

「会社に問い合わせるとき」の **「レポートをコピー」** を押すと、日付・行き先・荷物・点数・単価・金額・会社の金額・差がまとまった文章ができます。そのままLINEやメールに貼り付けられます。紙で渡すときは「印刷・PDF」。

> 目的は、会社と自分のどちらにとってもはっきりした給料にすることです。自分の記録ミスだった場合は「自分の記録ミス」にしておきましょう。

---

## 5. 機種変更・もしものとき

- 「設定」→「バックアップ・機種変更」→ **「バックアップを保存」**。できたファイルはGoogleドライブやLINEの自分あてに置いておきます（**月に1回がおすすめ**）
- 新しいスマホでは「バックアップから戻す」でそのファイルを選びます
- 注意：iPhoneは、アプリを長い間開かないと保存したデータが消されることがあります。ホーム画面に置いて毎日使っていれば普通は大丈夫ですが、バックアップもしておくと安心です

## 6. 困ったとき

| こんなとき | どうする |
|---|---|
| 金額が0円になる | 「⚠ 単価未設定」が出ていないか見る → 設定の単価表に金額を入れる |
| 夜中に記録すると日付が次の日になる | 設定 →「夜中の運行」で「朝○時より前は前日」を選ぶ |
| 会社の日ごとの金額と毎日少しずつ違う | 会社の金額に距離手当が含まれているかもしれません。設定 →「会社明細の日ごとの金額の中身」を切り替えてみる |
| 間違えて消した | 「もう一度押すと実行」と出たときだけ消えます。消してしまったらバックアップから戻します |
